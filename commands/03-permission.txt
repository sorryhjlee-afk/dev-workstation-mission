#  [사용법 - 꼭 bash 터미널에서 하세요]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널]  (단축키 Ctrl + `)
#   3. 터미널 패널 오른쪽 위 [v] 를 눌러 'Git Bash' 를 고릅니다.
#      프롬프트가  사용자@PC MINGW64 ~ $  처럼 '$' 로 끝나면 bash 입니다.
#      'PS C:\...>' 로 보이면 PowerShell 이니 반드시 Git Bash 로 바꾸세요.
#   4. 아래 명령을 '한 줄씩' 복사해서 붙여넣고 Enter 를 누릅니다.
#   5. # 으로 시작하는 줄은 설명이라 같이 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   "누가 이 파일을 읽고(r) / 쓰고(w) / 실행할(x) 수 있는가" 를 바꿔 봅니다.
#
#   * 리눅스 : chmod 숫자 3자리.  r=4, w=2, x=1 을 더합니다.
#       644 = 소유자 읽기+쓰기(6) / 그룹 읽기(4) / 나머지 읽기(4)  -> 실행 불가
#       755 = 소유자 7 / 그룹 5 / 나머지 5                        -> 실행 가능
#       700 = 소유자만 전부 가능, 나머지는 아무것도 못 함
#   * 윈도우 : icacls 로 봅니다.  F=모두, M=수정, RX=읽기+실행
#
#   리눅스 권한은 ubuntu 컨테이너 안에서 실습합니다. (윈도우에 리눅스를 안 깔아도 됩니다)
# ============================================================================

# (0) ★ 윈도우 Git Bash 전용 준비 한 줄 (맥/리눅스에서는 필요 없습니다)
#     Git Bash 는 /usr/share/... 처럼 / 로 시작하는 글자를 윈도우 경로로
#     자동으로 바꿔 버립니다. 그러면 docker 명령이 엉뚱한 곳을 가리킵니다.
#     터미널을 새로 열 때마다 이 한 줄을 먼저 실행하세요.
export MSYS_NO_PATHCONV=1

# (1) 리눅스식으로 지금 권한 보기 (Git Bash 가 흉내 내서 보여 줍니다)
ls -l Dockerfile
ls -ld config

# (2) 윈도우 진짜 권한(ACL) 보기
icacls Dockerfile
icacls config

# (3) 리눅스 : 권한 변경 전/후를 한 번에 보여 주는 실습 스크립트 실행
#     (labs/permission-lab.sh 파일 안에 무슨 일을 하는지 한글 설명이 있습니다)
docker run --rm -v "$(pwd)/labs:/labs" ubuntu:24.04 bash /labs/permission-lab.sh

# [성공하면?]
#   run-demo.sh = 644 (-rw-r--r--)  ->  실행하면 Permission denied, exit-code=126
#   chmod 755 뒤                    ->  permission-ok 출력, exit-code=0
#   mydir 을 700 으로 바꾸면 다른 사용자(tester)는 Permission denied
