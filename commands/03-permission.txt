# ============================================================================
#  STEP 03. 권한 실습 (파일 1개 + 디렉토리 1개)
# ============================================================================
#  [사용법]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널] 을 누릅니다.  (단축키 Ctrl + `)
#   3. 아래 명령을 '한 줄씩' 복사해서 터미널에 붙여넣고 Enter 를 누릅니다.
#   4. # 으로 시작하는 줄은 설명이라 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   "누가 이 파일을 읽고(r) / 쓰고(w) / 실행할(x) 수 있는가" 를 바꿔 봅니다.
#
#   * 윈도우 : icacls 로 봅니다.  F=모두, M=수정, RX=읽기+실행
#   * 리눅스 : chmod 숫자 3자리.  r=4, w=2, x=1 을 더합니다.
#       644 = 소유자 읽기+쓰기(6) / 그룹 읽기(4) / 나머지 읽기(4)  -> 실행 불가
#       755 = 소유자 7 / 그룹 5 / 나머지 5                        -> 실행 가능
#       700 = 소유자만 전부 가능, 나머지는 아무것도 못 함
#
#   리눅스 권한은 ubuntu 컨테이너 안에서 실습합니다. (윈도우에 리눅스를 안 깔아도 됩니다)
# ============================================================================

# (1) 윈도우 : 파일 1개의 권한 보기
icacls Dockerfile

# (2) 윈도우 : 디렉토리 1개의 권한 보기
icacls config

# (3) 리눅스 : 권한 변경 전/후를 한 번에 보여 주는 실습 스크립트 실행
#     (labs/permission-lab.sh 파일 안에 무슨 일을 하는지 한글 설명이 있습니다)
docker run --rm -v "${PWD}\labs:/labs" ubuntu:24.04 bash /labs/permission-lab.sh

#   chmod 755 뒤                    ->  permission-ok 출력, exit-code=0
#   mydir 을 700 으로 바꾸면 다른 사용자(tester)는 Permission denied
