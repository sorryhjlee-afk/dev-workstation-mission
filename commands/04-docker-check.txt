# ============================================================================
#  STEP 04. Docker 설치 및 기본 점검
# ============================================================================
#  [사용법]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널] 을 누릅니다.  (단축키 Ctrl + `)
#   3. 아래 명령을 '한 줄씩' 복사해서 터미널에 붙여넣고 Enter 를 누릅니다.
#   4. # 으로 시작하는 줄은 설명이라 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   도커가 깔려 있는지, 그리고 '엔진(데몬)'이 실제로 돌고 있는지 확인합니다.
#   엔진이 꺼져 있으면 모든 docker 명령이 실패하므로 이 단계를 꼭 먼저 합니다.
# ============================================================================

# (1) 버전 확인
docker --version

# (2) 엔진 상태 전체 보기 (출력이 아주 깁니다)
docker info

# (3) 길어서 보기 힘들면 핵심만
docker info --format "ServerVersion={{.ServerVersion}} / OS={{.OperatingSystem}} / CPUs={{.NCPU}}"

# [성공하면?]
#   ServerVersion 에 숫자가 보이면 엔진이 살아 있는 것입니다.
#
# [실패하면?]
#   "Docker Desktop is unable to start" 또는 "error during connect" 가 나오면
#   -> 작업표시줄에서 Docker Desktop 을 실행하고 1~2분 기다린 뒤 다시 하세요.
#   -> 그래도 안 되면 WSL 이 없는 경우입니다. 관리자 PowerShell 에서:
#      wsl --install --no-distribution    (실행 후 컴퓨터 재부팅)
