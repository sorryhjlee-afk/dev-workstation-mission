#  [사용법 - 꼭 bash 터미널에서 하세요]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널]  (단축키 Ctrl + `)
#   3. 터미널 패널 오른쪽 위 [v] 를 눌러 'Git Bash' 를 고릅니다.
#      프롬프트가  사용자@PC MINGW64 ~ $  처럼 '$' 로 끝나면 bash 입니다.
#      'PS C:\...>' 로 보이면 PowerShell 이니 반드시 Git Bash 로 바꾸세요.
#   4. 아래 명령을 '한 줄씩' 복사해서 붙여넣고 Enter 를 누릅니다.
#   5. # 으로 시작하는 줄은 설명이라 같이 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   Git    = 내 컴퓨터에서 '변경 기록을 저장'하는 도구   (게임의 세이브)
#   GitHub = 그 기록을 인터넷에 올려 공유하는 서비스     (세이브를 올리는 클라우드)
#
#   * 주의 : 비밀번호와 토큰은 절대 명령어나 문서에 적지 않습니다.
#   * 이메일은 GitHub 가 주는 noreply 주소를 쓰면 실제 메일이 공개되지 않습니다.
#     (GitHub - Settings - Emails 에서 확인 가능)
# ============================================================================

# (1) 내 정보 등록 (따옴표 안을 내 것으로 바꾸세요)
git config --global user.name "내이름"
git config --global user.email "아이디@users.noreply.github.com"
git config --global init.defaultBranch main

# (2) 설정 확인 (과제에 이 결과를 기록합니다)
git config --list

# (3) 이 폴더를 Git 저장소로 만들기
git init

# (4) 상태 보기 (?? 는 아직 저장 안 한 새 파일이라는 뜻)
git status --short

# (5) 전부 담고 저장하기
git add .
git commit -m "feat: 개발 워크스테이션 구축 미션"

# (6) 브랜치 이름을 main 으로 (init.defaultBranch 를 안 했다면 master 로 되어 있습니다)
git branch -M main
git branch --show-current

# (7) 기록 확인
git log --oneline

# (8) GitHub 에서 빈 저장소를 먼저 만듭니다
#     github.com - 오른쪽 위 [+] - New repository
#     이름: dev-workstation-mission / Public 선택
#     'Add a README file' 은 체크 해제 (체크하면 push 할 때 충돌납니다)

# (9) 원격 저장소 연결 (아이디를 내 것으로 바꾸세요)
git remote add origin https://github.com/아이디/dev-workstation-mission.git
git remote -v

# (10) 인터넷에 올리기 (처음이면 로그인 창이 뜹니다)
git push -u origin main

# [VS Code 로 하는 방법]
#   1. 왼쪽 아래 사람 모양 아이콘 - Sign in with GitHub - 브라우저에서 Authorize
#   2. 왼쪽 '소스 제어' 아이콘 (가지 세 개 모양) 클릭
#   3. 메시지 칸에 설명을 쓰고 체크(V) 버튼으로 커밋
#   4. 'Publish Branch' 또는 'Sync Changes' 클릭
#   5. 연동이 끝나면 왼쪽 아래에 내 GitHub 아이디가 보입니다 -> 이 화면을 캡처해 제출
