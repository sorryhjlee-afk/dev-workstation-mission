#  STEP 01. 실행 환경 확인
# ============================================================================
#  [사용법 - 꼭 bash 터미널에서 하세요]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널]  (단축키 Ctrl + `)
#   3. 터미널 패널 오른쪽 위 [v] 를 눌러 'Git Bash' 를 고릅니다.
#      프롬프트가  사용자@PC MINGW64 ~ $  처럼 '$' 로 끝나면 bash 입니다.
#      'PS C:\...>' 로 보이면 PowerShell 이니 반드시 Git Bash 로 바꾸세요.
#   4. 아래 명령을 '한 줄씩' 복사해서 붙여넣고 Enter 를 누릅니다.
#   5. # 으로 시작하는 줄은 설명이라 같이 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   내 컴퓨터에 Docker / Git / VS Code 가 제대로 깔려 있는지,
#   그리고 지금 쓰는 터미널이 정말 bash 인지 확인합니다.
#   과제에 "실행 환경(OS/쉘/터미널, Docker 버전, Git 버전)" 을 적어야 하므로
#   여기서 나온 결과를 그대로 README 에 옮겨 적습니다.
# ============================================================================

# (1) 지금 쓰는 터미널이 bash 가 맞는지 (가장 먼저 확인!)
echo "$BASH_VERSION"

# (2) bash 자세한 버전
bash --version | head -n 1

# (3) 운영체제 정보
uname -a

# (4) 윈도우 버전 (윈도우에서만 나옵니다)
cmd.exe //c ver

# (5) 도커 버전
docker --version

# (6) 도커 컴포즈 버전
docker compose version

# (7) 깃 버전
git --version

# (8) VS Code 버전
code --version

# [성공하면?]
#   (1) 에서 5.x 같은 숫자가 보이면 bash 가 맞습니다. 빈 줄이면 PowerShell 입니다.
#   (5)~(7) 에 version 글자와 숫자가 보이면 OK.
#
# [실패하면?]
#   'code' 를 못 찾는다고 나오면 VS Code 에서 Ctrl+Shift+P 를 누르고
#   "shell command" 를 검색해 'PATH에 code 명령 설치' 를 한 번 실행하세요.
