# ============================================================================
#  STEP 01. 실행 환경 확인
# ============================================================================
#  [사용법]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널] 을 누릅니다.  (단축키 Ctrl + `)
#   3. 아래 명령을 '한 줄씩' 복사해서 터미널에 붙여넣고 Enter 를 누릅니다.
#   4. # 으로 시작하는 줄은 설명이라 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   내 컴퓨터에 Docker / Git / VS Code 가 제대로 깔려 있는지 확인합니다.
#   과제에 "실행 환경(OS/쉘/터미널, Docker 버전, Git 버전)" 을 적어야 하므로
#   여기서 나온 결과를 그대로 README 에 옮겨 적습니다.
# ============================================================================

# (1) 도커 버전
docker --version

# (2) 도커 컴포즈 버전
docker compose version

# (3) 깃 버전
git --version

# (4) VS Code 버전
code --version

# (5) 지금 쓰는 터미널(쉘)이 무엇인지
$PSVersionTable.PSVersion.ToString()

# (6) 운영체제 이름과 빌드 번호
(Get-CimInstance Win32_OperatingSystem).Caption

# [성공하면?]
#   (1)~(3) 에 version 글자와 숫자가 보이면 OK.
#   'code' 를 못 찾는다고 나오면 VS Code 에서 Ctrl+Shift+P 를 누르고
#   "shell command" 를 검색해 'PATH에 code 명령 설치' 를 한 번 실행하세요.
