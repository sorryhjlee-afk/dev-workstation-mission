# ============================================================================
#  STEP 07. Dockerfile 로 커스텀 이미지 만들기
# ============================================================================
#  [사용법 - 꼭 bash 터미널에서 하세요]
#   1. VS Code 에서 이 저장소 폴더를 엽니다.  (파일 - 폴더 열기)
#   2. 메뉴 [터미널] - [새 터미널]  (단축키 Ctrl + `)
#   3. 터미널 패널 오른쪽 위 [v] 를 눌러 'Git Bash' 를 고릅니다.
#      프롬프트가  사용자@PC MINGW64 ~ $  처럼 '$' 로 끝나면 bash 입니다.
#      'PS C:\...>' 로 보이면 PowerShell 이니 반드시 Git Bash 로 바꾸세요.
#   4. 아래 명령을 '한 줄씩' 복사해서 붙여넣고 Enter 를 누릅니다.
#   5. # 으로 시작하는 줄은 설명이라 같이 복사해도 실행되지 않습니다.
#
#  [무엇을 하나요?]
#   공식 nginx 이미지를 '바탕'으로 삼고, 내 것으로 세 군데를 바꿉니다.
#     커스텀 1 : ENV APP_ENV=dev            -> 환경 변수 추가
#     커스텀 2 : config/default.conf 교체    -> 응답 헤더 X-Mission 추가, /data/ 목록 허용
#     커스텀 3 : app/ 교체                   -> 내가 만든 한국어 페이지로 바꿈
# ============================================================================

# (1) Dockerfile 내용 확인 (한 줄씩 한글 설명이 달려 있습니다)
cat Dockerfile

# (2) 이미지 굽기.  -t 는 이름표, 맨 끝의 . 은 '지금 폴더를 재료로 쓰라'는 뜻 (빼먹으면 에러)
docker build -t my-web-server:1.0 .

# (3) 만들어진 이미지 확인
docker images my-web-server

# (4) 커스텀 포인트가 실제로 들어갔는지 확인
docker image inspect my-web-server:1.0 --format "Env={{.Config.Env}}"
docker image inspect my-web-server:1.0 --format "Labels={{.Config.Labels}}"

# [성공하면?]
#   마지막에 naming to docker.io/library/my-web-server:1.0 done 이 보이면 성공!
#   Env 목록에 APP_ENV=dev 가 들어 있어야 합니다.
